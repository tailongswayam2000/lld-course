# Curriculum Plans: LLD Masterclass

This file holds the plan for the C++ Low Level Design (LLD) curriculum, structured logically into what is essential for interviews versus what is advanced.

## Structure

### Section 1: Important (The Core Interview Kit)
This section contains the absolute must-haves for standard 35-minute FAANG-style LLD interviews.
0. **00_CPP_Language_Refresher:** Syntax recap (OOPs Basics, Pointers, Templates, Polymorphism).
1. **01_Foundations:** Clean Code (KISS, DRY, YAGNI), Cohesion, Coupling.
2. **02_Modern_CPP_Design:** Rule of 3/5/0, Composition over Inheritance.
3. **03_Essential_Patterns:** The big four (Strategy, State, Factory, Observer).
4. **04_Delivery_Framework:** How to execute in an interview (Requirements -> Structure -> Implementation).
5. **05_Core_Practice_Problems:** Classic state machines, management systems, and games (Vending Machine, Parking Lot, Connect Four).

### Section 2: Advanced (The Extra Edge)
This section dives into complex, extensive topics for true engineering mastery.
1. **01_SOLID_Deep_Dive:** Breaking and fixing SRP, OCP, LSP, ISP, DIP.
2. **02_Advanced_Patterns:** The rest of the Gang of Four catalog.
3. **03_Concurrency:** Thread-safe design, locks, producer/consumer.
4. **04_Complex_Systems:** Message queues, rate limiters, task schedulers.

*Note: You are currently on **Section 1, Module 00_CPP_Language_Refresher**.*
